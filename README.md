# 個人金融資訊管理 V1.0.0-beta.1
第一階段基礎架構原型，非完整 V1.0.0，不可輸入真實金融資料。
## 部署
將 ZIP 解壓縮後的所有檔案上傳至獨立 GitHub Pages repo 根目錄，Settings > Pages > Deploy from a branch > main / root。Safari 開啟 HTTPS 網址，加入主畫面。使用獨立測試來源。
## 已實作
App shell、圖示、離線快取、IndexedDB 加密測試資料庫、PBKDF2/AES-GCM、復原金鑰解鎖、手動及閒置鎖定、基本背景遮蔽、簡單名稱與備註測試資料、寫入版本衝突檢查。
## 未實作
正式三大模組欄位與關聯、完整共用資料、附件、備份還原、密碼重設及金鑰輪替、歷史、封存、報表、提醒、容量管理、安全版本遷移、完整設定。未經安全審核及 iPhone 驗收。不代表正式規格縮減。
## 第一項測試 T01-01
